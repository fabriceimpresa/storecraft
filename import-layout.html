Importa layout .psd

dal file photoshop originale (.psd) alla nuova pagina di generazione di cartelli. la conversione legge il foglio, i due cartelli e i livelli, chiamati con i nomi dei componenti del menu di sinistra (riquadro-brand, logo-brand, claim-sx, descrizione, prezzo-finale…), e abbina a ognuno il suo modulo comune. il file resta sul computer: si legge solo nel browser

// cartellini: la base comune dei cartellini non c'è ancora. per ora import layout crea solo pagine di cartelli

trascina qui il file .psd, o clicca per sceglierlo

nessun file scelto

2

conversione

3

risultato

associa a pagina somigliante già esistente oppure crea una nuova base comune

passa sopra un numero, un livello o un modulo per seguire il filo; clicca per i valori dell'elemento

costruisce la pagina dai dati letti: posizioni, font e colori del .psd, moduli comuni nel pannello
